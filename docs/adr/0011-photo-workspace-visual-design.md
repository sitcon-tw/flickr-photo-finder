# ADR 0011: 照片優先的工作台設計

## 狀態

Accepted，2026-09-16。

## 背景

維護者彙整的使用與演講回饋肯定找圖流程，但認為介面「整體像管理後台，缺少設計感」。改版前的介面中，用途、搜尋、候選、AI 說明與索引概覽具有接近的視覺權重，輔助側欄在中型視窗中排到照片上方。這份決策以這些質性回饋與介面檢視為依據，未經完整使用者研究。

設計目標是讓照片更容易檢視、操作層級更清楚，並呈現 SITCON 常設品牌，同時維持已獲肯定的搜尋、篩選、候選與分享流程。產品定位依 [ADR 0008](0008-photo-index-product-boundary.md)，以完成找圖任務為核心。

## 決策

- 採用照片優先的工作台：照片與找圖控制項構成主要操作區，候選清單支援比較與分享，AI 說明與索引概覽按需展開。
- 桌面、平板與手機提供相同的找圖能力，依可用寬度調整排列與密度。連結、展開狀態、選取狀態與鍵盤焦點皆有可辨識的提示，操作入口在觸控裝置上直接可見。
- 篩選採緊湊排列，以欄位名稱、選取摘要與已套用條件表達目前狀態。進階條件收合只影響呈現，不改變篩選結果。
- 使用 SITCON [官方品牌規範](https://sitcon.org/branding/) 的常設識別，以字級、留白與介面配色建立層級。照片以原色與完整構圖呈現，讓使用者判斷素材本身；文案採台灣慣用繁體中文。
- 淺色與深色是同等支援的介面外觀。預設採用瀏覽器偏好，使用者透過單一圖示按鈕切換，手動選擇保存在瀏覽器本機。外觀偏好獨立於搜尋與分享狀態，讓連結接收者使用自己的閱讀設定。

## 取捨與替代方案

只調整配色與圓角，無法解決輔助資訊與照片爭奪注意力的問題；展示型大圖首頁則會增加進入找圖操作的距離。工作台布局以照片判斷為優先，代價是 AI 說明與索引概覽需要額外展開。

緊湊控制項能增加照片的可見空間，但無法在每個按鈕內完整顯示長選項。選取摘要提供快速辨識，選單與已套用條件提供完整內容，讓使用者確認結果受哪些條件影響。

贊助品項需要同時接受片段文字與完整品項，因此使用可直接輸入的欄位，並以外框、配色與建議選單和其他篩選建立一致性。已選值逐項呈現，接受多選後增加高度的代價，換取直接確認與移除條件的便利性。

明暗外觀適應不同閱讀環境，也增加元件與狀態的配色驗證成本。兩種外觀共用元件與色彩變數，以控制維護範圍。單一圖示按鈕節省頁首空間，其功能與切換結果透過文字提示及無障礙名稱補充說明。

## 重新評估條件

若實際找圖任務顯示使用者難以發現篩選、確認已選條件或完成候選操作，應重新評估控制項密度、資訊層級與展開方式。新增活動展示或跨裝置外觀同步需求時，應另行評估產品定位與偏好儲存邊界。
